# Hayabumi（はやぶみ）

広告のない、軽くて速い Windows 用メールアプリ。

- 要件定義: [docs/requirements.md](docs/requirements.md)
- 開発の手引き: [docs/development.md](docs/development.md)

## 動作環境

- Windows 10 / 11（64bit）
- 管理者権限は不要（ユーザー単位でインストール）

## インストール

[Releases](../../releases) から `Hayabumi-win-Setup.exe` をダウンロードして実行します。

コード署名をしていないため、初回は「Windows によって PC が保護されました」と表示されます。
［詳細情報］→［実行］の順に選ぶとインストールできます。

## できること（0.3）

**受信・閲覧**
- IMAP / POP3 アカウント（パスワード・アプリ パスワード、Google・Microsoft でのサインイン）
- すべてのアカウントをまとめた「すべての受信トレイ」「未読」「フラグ付き」
- 新着の即時受信（IMAP IDLE）と定期受信、Windows の通知、タスクトレイ常駐、未読数のバッジ
- 数十万通のフォルダでも軽い一覧表示、日本語の全文検索（部分一致）
- 本文の表示（日本語の文字化け対策、外部画像は既定でブロック、スクリプトは常に無効）
- 既読・未読、フラグ、移動、削除（複数選択可。オフラインでも操作でき、接続時にサーバーへ反映）
- フォルダの作成・名前の変更・削除、添付ファイルの保存

**送信**
- 新規作成・返信・全員に返信・転送、署名、添付（ドラッグ＆ドロップ可）、下書きの自動保存
- 宛先の入力候補（アドレス帳と送受信の履歴）、アドレス帳とグループ
- 誤送信対策: 送信前に宛先と添付を一つずつ確認（社外は強調）、添付忘れ・一斉送信の警告、送信の取り消し
- 送信できなかったメールの自動再送、文字コードの選択（UTF-8 / ISO-2022-JP）

**その他**
- 設定（受信間隔、送信の取り消し時間、自動起動、社内ドメインなど）、データフォルダの移動
- 自動更新

Google・Microsoft でのサインインを使うには、事前にアプリの登録が必要です（[docs/oauth-setup.md](docs/oauth-setup.md)）。
